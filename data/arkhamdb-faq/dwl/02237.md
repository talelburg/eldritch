# Rampaging Creatures (02237)

Rulings last updated on ArkhamDB 2017-06-05; fetched 2026-08-15. Source: <https://arkhamdb.com/card/02237>

- The **Forced** effect moves each [Brood of Yog-Sothoth](https://arkhamdb.com/card/02255) in play. If you have multiple Broods in play, after selecting a random location for the first brood, select another random location for the second and so on. It is possible that all Broods will try to move to the same place.

- The **Forced** effect moves each [Brood of Yog-Sothoth](https://arkhamdb.com/card/02255) irrespective of if they were at the same location as an investigator or not, and irrespective of whether they are ready or exhausted.
