# Eon Chart (08100)

Rulings last updated on ArkhamDB 2023-09-02; fetched 2026-08-15. Source: <https://arkhamdb.com/card/08100>

- **Q:** If an effect allows you to take or perform multiple consecutive actions, such as with [Eon Chart](https://arkhamdb.com/card/08100) or [Nimble](https://arkhamdb.com/card/60317), are there player windows between these actions where I’d be able to play a fast card or resolve a free triggered ability? **A:** No, there are no player windows between multiple consecutive actions. - FAQ, v.2.1, August 2023

- **NB:** ArkhamDB now incorporates errata from the Arkham Horror FAQ in its card text, so the ArkhamDB text and the card image above differ, as the ArkhamDB text has been edited to contain this erratum (updated January 2022): **Erratum**: This card’s [fast] ability should now read: "…choose and take 2 different actions of the following, in any order (move, evade, or investigate)." - FAQ, v.2.1, August 2023
