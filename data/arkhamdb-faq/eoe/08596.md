# To the Forbidden Peaks (08596)

Rulings last updated on ArkhamDB 2023-09-02; fetched 2026-08-15. Source: <https://arkhamdb.com/card/08596>

- **Q:** In the scenario [To the Forbidden Peaks](https://arkhamdb.com/card/08596), I am moving to a location which has [Through the Ice](https://arkhamdb.com/card/08699) attached – I’m doing the test and I draw the [cultist] token (HARD/EXPERT variant): I have to move to the location below me. What happens with the test? Is it canceled, because moving to the location with attached treachery is aborted by drawing the chaos token? Or does it continuing resolving (in this situation what happens with moving if I pass the test?) **A:** Upon further inspection, we believe that the [cultist] token in To the Forbidden Peaks should have specified that the **Forced** move occurs after the skill test ends. Please treat the card and token as if this were the case.

- **NB:** ArkhamDB now incorporates errata from the Arkham Horror FAQ in its card text, so the ArkhamDB text and the card image above differ, as the ArkhamDB text has been edited to contain this erratum (updated January 2022): **Erratum**: These card’s [cultist] effects should read "If you fail, after this test ends…" - FAQ, v.2.1, August 2023
