# Sharpshooter (60327)

Rulings last updated on ArkhamDB 2023-06-27; fetched 2026-08-15. Source: <https://arkhamdb.com/card/60327>

**Q:** I want to ask about the first option of Sharpshooter's [reaction] ability. It reads "All modifiers to your [combat] for this attack modify your [agility] instead." Does this mean that I can commit cards with only [combat] skill icon in this skill test (e.g. [Overpower](https://arkhamdb.com/card/01091)/[Vicious Blow](https://arkhamdb.com/card/01025))?

**A:** No; the first ability on Sharpshooter makes the resulting skill test require agility icons to be committed instead of combat icons, so you could not commit [Overpower](https://arkhamdb.com/card/01091) to that test. (Although, if you had any passive modifiers to your combat value in play, such as [Beat Cop](https://arkhamdb.com/card/01018), then those would modify your agility instead of your combat value for the test.) (Rules Q&A, June 2023)
