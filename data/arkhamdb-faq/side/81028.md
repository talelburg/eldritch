# The Rougarou (81028)

Rulings last updated on ArkhamDB 2017-05-02; fetched 2026-08-15. Source: <https://arkhamdb.com/card/81028>

- Only the investigator engaging The Rougarou needs to be in its location. Other investigators can contribute clues from anywhere.

- There is no limit on [The Rougarou](https://arkhamdb.com/card/81028)'s **forced** effect. It triggers as soon as its condition (1 damage per investigator in a single phase) is met. It can trigger multiple times in the same phase.
