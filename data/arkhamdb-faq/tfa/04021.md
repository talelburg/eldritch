# Dr. Elli Horowitz (04021)

Rulings last updated on ArkhamDB 2018-07-03; fetched 2026-08-15. Source: <https://arkhamdb.com/card/04021>

- **Q:** If you use [Dr. Elli Horowitz](https://arkhamdb.com/card/04021) to get [The Chthonian Stone](https://arkhamdb.com/card/04030), does the token still get sealed to the stone? **A** Yes! Seal is an additional cost for the card to enter play, so anytime the Chthonian Stone enters play by any means, you must seal the designated chaos token on it (and if you cannot, it cannot enter play).
