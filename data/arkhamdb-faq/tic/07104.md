# Underground River (07104)

Rulings last updated on ArkhamDB 2022-08-29; fetched 2026-08-15. Source: <https://arkhamdb.com/card/07104>

- **Q:** What happens if an [Underground River](https://arkhamdb.com/card/07104) becomes fully flooded while it is unrevealed, and then becomes revealed? **A:** It cannot be fully flooded once it has been revealed, so set it to the nearest state (in this case, partially flooded). Its forced effect fails. - FAQ, v.2.0, August 2022
