# "Lucky" Penny (07224)

Rulings last updated on ArkhamDB 2022-09-21; fetched 2026-08-15. Source: <https://arkhamdb.com/card/07224>

- **Q:** Can you use ["Lucky" Penny](https://arkhamdb.com/card/07224) to seal [curse] tokens you have treated as [bless] tokens on [Nephthys](https://arkhamdb.com/card/07262)? Since the lasting effect caused by "Lucky" Penny has no explicit expiration, what happens? And if you can seal them on Nephthys, would they still count as [bless] tokens for the full time that they are sealed on Nephthys, so could you use her ability to release/return them to the supply? What would happen if "Lucky" Penny were to leave play while there were [curse] tokens treated as [bless] tokens sealed on Nephthys (if they can be sealed on her)? **A:** Though you are able to use “Lucky” Penny to treat [curse] tokens as [bless] tokens, this will only last for the duration of the skill test you’re using “Lucky” Penny on. Once they’re sealed on Nephthys (as the skill test ends), they will be considered [curse] tokens again, and cannot be released via her ability.
